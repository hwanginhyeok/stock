# AI 데이터센터 인프라 투자 분석 — Layer 4 네트워크 패브릭 심층 레포트

> 작성일: 2026-05-11 | 버전: v1.0 | 분류: 내부 리서치

---

## 1. Executive Summary

**핵심 3줄 요약**

1. AI 클러스터의 현재 병목은 **HBM 메모리 대역폭**이지만, 규모가 커질수록 **네트워크 패브릭(Layer 4)**이 다음 병목으로 급부상 중이다.
2. InfiniBand 독주 체제가 무너지고 있다 — AWS·Google·Meta 전환 완료, Microsoft 2026년 예고. **Ultra Ethernet Consortium(UEC)** 이 2025년 6월 스펙을 출시하며 전환을 가속한다.
3. **지금(2026)**: HBM + 네트워킹 장비 | **다음(2027~28)**: CPO 광 인터커넥트 + CXL | **장기(2029~30)**: 전력 그리드 + 액침 냉각이 핵심 병목이자 투자 기회다.

| 시계 | 핵심 병목 | 대표 수혜 기업 |
|------|-----------|----------------|
| 지금 (2026) | HBM 메모리 BW + 네트워크 패브릭 | SK Hynix, AVGO, ANET, ALAB |
| 단기 (2027~28) | CPO 광 인터커넥트 + CXL 메모리 풀링 | COHR, LITE, ALAB, Montage |
| 장기 (2029~30) | 전력 그리드 + 액침 냉각 + 스토리지 I/O | 전력 인프라, 냉각 전문기업 |

## 2. AI 인프라 스택 5계층

```
+----------------------------------------------------------+
| Layer 5: 애플리케이션/소프트웨어                          |
|  - AI 프레임워크, 오케스트레이션, MLOps                  |
|  - 대표: CRWV(CoreWeave), Databricks                    |
+----------------------------------------------------------+
| Layer 4: 네트워크 패브릭  ◀◀ 급속 병목화 중              |
|  - 클러스터 간 고속 연결, 스위치, 트랜시버               |
|  - 대표: AVGO(Tomahawk), ANET, NVDA(Spectrum-X)         |
+----------------------------------------------------------+
| Layer 3: 가속기 + 메모리  ◀◀ 현재 가장 심각한 병목       |
|  - GPU/NPU + HBM3E/HBM4, NVLink, PCIe                   |
|  - 대표: NVDA, SK Hynix, Micron, Samsung                |
+----------------------------------------------------------+
| Layer 2: 서버/전력/냉각  ◀◀ 신흥 병목 진입               |
|  - 랙 밀도, DLC/액침, UPS, PDU                          |
|  - 대표: 냉각: Vertiv, Eaton / 전력: 그리드 유틸리티    |
+----------------------------------------------------------+
| Layer 1: 물리 인프라                                      |
|  - 부지, 전력망 연결, 광섬유 백본                        |
|  - 대표: 데이터센터 리츠, 전력 회사                      |
+----------------------------------------------------------+
```

### 계층별 상세

| Layer | 분류 | 주요 기술 | 현재 상태 | 병목 수준 |
|-------|------|-----------|-----------|-----------|
| L5 | 소프트웨어 | CUDA, PyTorch, 오케스트레이션 | 성숙 | 낮음 |
| L4 | 네트워크 | InfiniBand, RoCE v2, UEC, CPO | 전환기 | **높음 (급등)** |
| L3 | 가속기+메모리 | H100/B200/R100, HBM3E/4, NVLink | 공급 부족 | **최고 (현재)** |
| L2 | 서버/냉각 | DLC, 액침, 400V PDU | 투자 급증 | **중간 (신흥)** |
| L1 | 물리 인프라 | 부지, 전력 계약 | 그리드 제약 | 중간 |

> **현재 병목 1위**: Layer 3 (HBM 메모리 대역폭)
> **다음 병목**: Layer 4 (네트워크 패브릭) — 클러스터 규모가 수만 GPU로 커지면서 급속 병목화

## 4. 핵심 기술 분석

### 4-1. RDMA/RoCE v2 vs InfiniBand — 현황과 승자

**InfiniBand (NVDA Quantum-X / NDR 400G / XDR 800G)**
- 2023년 AI 훈련 시장 점유율 ~80% (사실상 독점)
- 장점: 극저 지연(sub-μs), 하드웨어 기반 혼잡 제어, SHARP in-network 연산
- 단점: NVDA 생태계 종속, 가격 프리미엄, 범용 이더넷 인프라와 비호환
- 2026 현황: AWS/Google/Meta 이미 이더넷으로 전환 완료. Microsoft 2026년 전환 예고

**RoCE v2 (RDMA over Converged Ethernet)**
- 이더넷 위에서 RDMA 구현 — 기존 이더넷 인프라 활용 가능
- 문제: 패킷 손실 시 성능 급락, 혼잡 제어(PFC/ECN)가 복잡
- NVDA Spectrum-X가 RoCE v2 최적화로 IB 대비 95% 성능 달성 주장

**판정: Ethernet 진영이 장기 승자**

```
2023: InfiniBand 80% vs Ethernet 20%
2024: InfiniBand 65% vs Ethernet 35%  ← 전환 가속
2026: InfiniBand 45% vs Ethernet 55%  ← 교차점 통과
2028: InfiniBand 20% vs Ethernet 80%  ← UEC 안착 후
```

하이퍼스케일러의 이더넷 전환이 완료되면 IB는 NVDA 내부 클러스터용으로 수요 유지.
장비 투자는 **AVGO(Tomahawk 스위치), ANET(클라우드 타이탄 네트워크), MRVL(Prestera)** 수혜.

---

### 4-2. Ultra Ethernet Consortium (UEC) vs InfiniBand

**UEC 개요**
- 2023년 AMD, Arista, Cisco, HPE, Intel, Microsoft 등 설립
- 목표: 이더넷 기반 AI/HPC 전용 프로토콜 — IB 성능을 오픈 표준으로 구현
- UEC 1.0 스펙: **2025년 6월 출시**
- 핵심 기술: 향상된 혼잡 제어, 다경로 전송, 멀티파스 로드밸런싱

**전황**

| 구분 | InfiniBand | UEC |
|------|-----------|-----|
| 표준 주체 | NVDA (사실상 독점) | 오픈 컨소시엄 |
| 지연 | sub-μs (최저) | μs급 (개선 중) |
| 생태계 | NVDA 전용 | 멀티벤더 |
| 비용 | 고가 프리미엄 | 이더넷 가격대 |
| 현재 채택 | NVDA 클러스터 | AWS/Google/Meta |
| 2026+ | 감소 추세 | 급속 확산 |

**핵심 분기점**: UEC 1.0이 실제 데이터센터 배포에서 성능을 입증하면 IB의 존재 이유가 NVDA 내부 클러스터로 한정된다.

---

### 4-3. Co-Packaged Optics (CPO) 상용화 타임라인

**CPO란?**
- 기존: 분리형 플러그인 트랜시버 (QSFP-DD, OSFP) — 보드 에지에서 광 변환
- CPO: 광 엔진을 스위치 ASIC과 동일 패키지에 통합 — 전력 40~60% 절감, 대역폭 4x 향상

**타임라인**

```
2024: PoC 단계 — Ayar Labs NVIDIA와 공동 시연
2025: 소규모 양산 — Coherent, Intel CPO 제품 출하 시작
2026: 얼리어답터 도입 — 신규 스위치 설계에 CPO 옵션 포함
2027: 주류 진입 초기 — 400G/800G 스위치 CPO 표준화
2028: CPO SAM $5B 돌파 예상 (Coherent 추정 SAM $15B까지 성장)
2030: CPO가 고밀도 AI 클러스터 표준
```

**핵심 기업**
- **Coherent (COHR)**: NVIDIA로부터 $4B 전략 투자, CPO SAM $15B 목표
- **Lumentum (LITE)**: Q2 FY2026 매출 $665.5M (YoY +65%), EML 레이저 독점 공급
- **Ayar Labs**: UCIe 기반 인-패키지 광 인터커넥트, NVDA·Intel 협업

**투자 포인트**: CPO는 2026~27년이 진입 타이밍. 스위치 1개당 트랜시버 수요가 CPO 전환으로 감소하지만, 광 엔진 단가가 올라가므로 Coherent·Lumentum의 매출 총액은 증가한다.

---

### 4-4. CXL 메모리 풀링

**CXL(Compute Express Link) 개요**
- PCIe 6.0 기반 고속 캐시 코히어런트 인터커넥트
- CXL 메모리 풀링: 여러 서버가 공유 메모리 풀을 사용 — GPU 메모리 용량 한계 해소
- HBM을 CXL로 확장하면 GPU 로컬 메모리 한계(80GB HBM3E)를 TB급으로 확장 가능

**현황 및 타임라인**

| 연도 | 이정표 |
|------|--------|
| 2023 | CXL 2.0 기반 초기 제품 출시 (ALAB, Montage) |
| 2024 | Intel Xeon 6, AMD EPYC 9004 CXL 지원 |
| 2025 | ALAB PCIe 6.0 레티머/스위치 양산 |
| 2026 | 대형 AI 클러스터 CXL 메모리 풀링 실증 |
| 2027 | CXL 3.1 — 멀티노드 풀링 표준화 |

**수혜 기업**
- **Astera Labs (ALAB)**: CXL 레티머+스위치 선도. 2025 매출 $852.5M (YoY +115%)
- **Montage Technology**: CXL 컨트롤러, 중국 클라우드 수요 집중

---

### 4-5. 냉각: DLC vs 액침 냉각

**배경**: GPU 밀도 상승으로 랙당 소비 전력이 10kW→40kW→100kW+로 상승. 기존 공냉으로는 한계.

| 구분 | 직접 액체 냉각 (DLC) | 액침 냉각 (Immersion) |
|------|---------------------|----------------------|
| 방식 | 콜드플레이트로 칩 직접 냉각 | 서버 전체를 냉각액에 담금 |
| 효율 | 공냉 대비 30~40% 절감 | 공냉 대비 50~70% 절감 |
| 비용 | 중간 | 높음 (초기 투자) |
| 도입 난이도 | 기존 랙 호환 | 전용 탱크/인프라 필요 |
| 현재 채택 | Meta, Google, NVDA DGX 기본 적용 | Microsoft Azure, 일부 특수 클러스터 |
| 2026 전망 | 40kW+ 랙 표준 | 100kW+ 초고밀도 랙 |

**판정**: 단기(~2027)는 DLC 주류, 장기(2028+)는 100kW 랙에서 액침이 불가피.

| Databricks | 비상장 | 데이터+AI 플랫폼 | 2025 ARR $3B+(E), IPO 대기 | AI 인프라 위에서 실제 수익 창출. IPO 시 관심 |

## 6. 병목 순서별 투자 전략

### 지금 (2026): HBM + 네트워크 패브릭에 올라타라

**핵심 논리**: HBM은 지금 공급이 가장 빡빡하고, 네트워크 패브릭은 병목화 진입 초기 — 두 곳 모두 수요가 명확히 보인다.

**우선 포지션**

| 기업 | 이유 |
|------|------|
| SK Hynix | HBM4 선도 + NVDA 독점 공급. 지금이 HBM 사이클 정점 |
| AVGO | 스위치 수주 잔고 $73B, AI ASIC 커스터마이징 수혜 |
| ANET | 2026 AI 네트워킹 목표 $3.25B. 하이퍼스케일러 전환 직접 수혜 |
| ALAB | CXL 선도 + 고성장. 메모리 병목 해소의 next step |
| CRWV | 계약 잔고 $56B 가시성. GPU 클라우드 수요 직접 반영 |

**피해야 할 것**: InfiniBand 의존도가 높은 포지션 (단독 IB 공급사). 전환 속도가 예상보다 빠를 수 있음.

---

### 다음 (2027~28): CPO와 CXL이 진짜 게임체인저

**핵심 논리**: 네트워크 병목이 폭발하면 CPO가 유일한 해법. CXL 메모리 풀링이 HBM 한계를 돌파하는 솔루션으로 부상.

**포지션 이동**

| 기업 | 타이밍 | 이유 |
|------|--------|------|
| COHR | 2026 하반기 진입 | CPO 양산 가시성 + NVDA 투자로 신뢰성 확보 |
| LITE | 지속 보유 | EML 레이저 수요는 CPO 확산에 비례해 증가 |
| ALAB | 지속 강화 | CXL 3.x 표준화 → TAM 급확장 |
| MRVL | 2026 하반기 | 커스텀 ASIC + CPO DSP 포트폴리오 |

**모니터링 지표**
- UEC 1.0 실제 대형 클러스터 배포 사례 (2026 하반기)
- CPO 양산 단가 — $x/Gbps가 플러그인 트랜시버 대비 경쟁력 확보 시점
- CXL 메모리 풀링 TCO 실증 결과

---

### 장기 (2029~30): 전력 그리드와 액침 냉각이 새 천장

**핵심 논리**: GPU 클러스터가 GW급으로 성장하면 전력 공급과 냉각이 물리적 한계. 이 시점에서 에너지 효율화 솔루션 기업이 가장 비싸진다.

**장기 포지션 고려**

| 액침 냉각 | Vertiv, 액침 전문기업 | 100kW+ 랙 표준화 불가피 |
| 핵/소형 원자력 | SMR 기업 | 데이터센터 전용 전원 구축 |
| 광 인터커넥트 | COHR, LITE | CPO 완전 전환 후 안정적 수익 |

## 7. 리스크 요인

### R-1. InfiniBand → Ethernet 전환 속도 불확실성

**리스크**: NVDA가 IB 생태계를 방어하기 위해 Spectrum-X를 공격적 가격으로 투하하거나 Ethernet 전환 기업에 GPU 공급을 우선순위 조정할 경우 전환 속도 둔화 가능.

**모니터링**: 하이퍼스케일러 분기별 네트워킹 CAPEX 내 IB vs Ethernet 비중 변화.

**영향 기업**: ANET (긍정), AVGO (중립), NVDA (IB 감소 vs Spectrum-X 증가 상쇄)

---

### R-2. HBM 공급 정상화 시점

**리스크**: 삼성이 HBM3E 인증을 2026년 중 통과하면 공급 경쟁이 격화되어 SK Hynix 프리미엄 소멸. HBM4 단가도 예상보다 빨리 하락 가능.

**모니터링**: 삼성 HBM4 NVDA 퀄 일정, SK Hynix HBM 점유율 분기별 변화.

**시나리오**

| 시나리오 | 확률(E) | 영향 |
|---------|---------|------|
| 삼성 HBM4 퀄 2026년 H2 통과 | 40% | SK Hynix 프리미엄 축소 |
| 삼성 HBM4 퀄 2027년 통과 | 45% | SK Hynix 우위 연장 |
| 삼성 HBM4 퀄 2028년 이후 | 15% | SK Hynix 독점 가격 유지 |

---

### R-3. CPO 상용화 지연 가능성

**리스크**: CPO는 열 관리, 패키징 수율, 표준화 문제가 복잡. 2027년 주류 진입 예상이 2028~29년으로 밀릴 경우 COHR 등 선투자 기업의 이익 실현 지연.

**구체적 장애물**
- 공정 수율: 광 엔진과 전기 ASIC의 이종 집적 패키징 수율 확보
- 열 관리: 광 소자의 온도 민감성 — 고밀도 패키징에서 열 분리 어려움
- 표준화: OIF CPO 표준이 2026년 최종 확정 예정, 지연 가능

**모니터링**: 2026년 OFC/ECOC 컨퍼런스에서 CPO 양산 발표 여부.

---

### R-4. 전력 그리드 병목

**리스크**: 미국/유럽 전력망이 AI 데이터센터 급증 수요를 따라가지 못할 경우 신규 클러스터 승인 자체가 불가능해짐. 이는 GPU 수요 둔화로 연결.

**현황**
- 버지니아 데이터센터 밸리(Ashburn): 신규 전력 접속 2~3년 대기
- 아일랜드 더블린: 그리드 용량 초과로 신규 데이터센터 모라토리엄
- 텍사스 ERCOT: 재생에너지 + AI 클러스터 혼재로 그리드 불안정 우려

**대응**: 하이퍼스케일러들이 SMR, 전용 발전소 계약으로 선제 대응 중. 단기 임시방편이나 5~7년 공사 기간으로 구조적 해소는 2030년대.
