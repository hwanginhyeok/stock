## 배경

사용자 트레이딩 스타일이 VWMA100 기반 추세 매수(메모리 `user_trading_style.md`)인데, 기존 `trend.py:classify_trend_regime`은 EMA 20/50/200 + ADX 사양으로 사용자 스타일과 불일치. SMA 5/10/20/50의 짧은 평균선과 VWMA100을 결합한 정배열 감지 + 눌림목 매수 시그널이 필요. 1H/4H/D 다중 타임프레임 대응이 최종 목표지만 D부터 MVP.

## 점수 공식

```
score = base[alignment]                   # 정배열 70 / 혼재 50 / 역배열 25
if close_vs_vwma >= 5:    score += 8
elif close_vs_vwma >= 0:  score += 4
elif close_vs_vwma <= -5: score -= 8
else:                     score -= 4      # 0% > x > -5%
if buy_signal:            score += 10
score = clamp(0, 100)
```

`delta_3d` = 현재 점수 - 3일 전 alignment 베이스 점수 (간이 추적; 정교화 시 시계열 캐시 필요)

TSLA 현재(2026-05-13) 4개 SMA는 정배열이지만 VWMA100이 SMA10/SMA20 사이에 끼어서 5개 체인 기준 "혼재". 이는 최근 거래량이 SMA10~SMA20 가격대($397~$411)에 집중되었다는 의미. 추세는 강하지만 거래량 가중 평균이 단순 평균보다 위라 "가벼운 상승" 신호 — VWMA 끼움은 분포 정보를 보존하는 정의의 장점.
