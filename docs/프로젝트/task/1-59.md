## 카드 데이터 스키마

각 카드 (`/api/tesla/headline-cards`):
```
key | label_ko | primary | primary_sub | delta | delta_pos | action | comment | color | source
```

- 비중: `primary=18.5%`, `delta=-3.5%p`, color는 ±2%p 임계로 green/amber/red
- 주가: `primary=$285.30`, `delta=+16.07%`, color는 손익 부호
- 모멘텀: `primary=58`, `primary_sub=혼재`, color는 60/40 임계 (실데이터 시 source=yfinance)
